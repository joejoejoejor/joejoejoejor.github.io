Valuing MBS Options

A Quantitative Analysis of Mortgage-Backed Securities with Prepayment Features

Overview

This project performs a comprehensive valuation of Mortgage-Backed Securities (MBS) and analyzes the impact of prepayment options on their value, duration, and convexity. The analysis employs interest rate modeling through the Black-Derman-Toy (BDT) framework, calibrated using the Nelson-Siegel yield curve model.

Mortgage-backed securities represent a pool of mortgage loans packaged together as tradable securities. A key feature of these instruments is the prepayment option held by homeowners, which introduces complexity in their valuation. When interest rates decline, homeowners are more likely to refinance their mortgages, effectively exercising an embedded call option that affects the MBS value and risk characteristics.

Key Components
  • Nelson-Siegel model for yield and volatility curve estimation
  • Black-Derman-Toy (BDT) short rate tree construction
  • MBS valuation with and without prepayment options
  • Duration and convexity analysis under different interest rate scenarios
  • Visualization of value, duration, and convexity sensitivity

Nelson-Siegel Model

The Nelson-Siegel model provides a parsimonious and flexible framework for fitting the term structure of interest rates. The model represents yields as a function of maturity using four parameters that capture level, slope, and curvature characteristics of the yield curve.

Model Specification

The Nelson-Siegel model expresses yields and volatilities as:

$$Y(m) = \beta_0 + (\beta_1 + \beta_2)\frac{1-e^{-m/\tau}}{m/\tau} - \beta_2 e^{-m/\tau}$$

Where:

  • \(\beta_0\) represents the long-term level of interest rates
  • \(\beta_1\) captures the slope of the yield curve
  • \(\beta_2\) controls the curvature (hump)
  • \(\tau\) determines the maturity at which the curvature effect is maximized
  • \(m\) is the time to maturity

Parameter Estimation

The parameters are estimated by minimizing the sum of squared errors between observed and fitted values using MATLAB's fminsearch function. This approach is applied separately to both yield and volatility data.

% Define error function for yield fitting errorNelsonSiegelYield = @(par) (sum((yieldData.y - ( ... par(1) + ... (par(2)+par(3)).*(1-exp(-yieldData.m./par(4)))./(yieldData.m./par(4)) - ... par(3).*exp(-yieldData.m./par(4)) ... )).^2)); % Optimize parameters [parMinYield, errorMinYield] = fminsearch(errorNelsonSiegelYield, startPar); % Similarly for volatility errorNelsonSiegelVol = @(par) (sum((yieldData.vol - ( ... par(1) + ... (par(2)+par(3)).*(1-exp(-yieldData.m./par(4)))./(yieldData.m./par(4)) - ... par(3).*exp(-yieldData.m./par(4)) ... )).^2)); [parMinVol, errorMinVol] = fminsearch(errorNelsonSiegelVol, startPar);

After parameter estimation, fitted yield and volatility functions can be evaluated at any maturity, providing smooth curves that interpolate between observed market data points. This enables us to obtain yields and volatilities for all 360 monthly periods needed for the MBS valuation.

Short Rate Tree Construction

The interest rate dynamics are modeled using a binomial short rate tree in the Black-Derman-Toy framework. This recombining tree is calibrated to match both the observed zero-coupon bond prices (derived from yields) and the term structure of volatility.

Tree Calibration Methodology

The short rate tree is constructed iteratively, step by step. At each time step, we solve for two parameters:

  • The lowest short rate at that time step
  • The volatility parameter that determines the spacing between rates

Initial Node

The first node is calibrated to match the observed price of a zero-coupon bond maturing at the first time step:

% Calibrate first node (no volatility matching needed) i = 1; thisPrice = observedData.price(i); thisMaturity = observedData.m(i); % Error function: difference between model and market price thisError = @(r) (1*exp(-r*thisMaturity) - thisPrice)^2; % Find rate that minimizes error thisR = fminsearch(thisError, startR); shortTree(i,1) = thisR;

Subsequent Nodes

For subsequent time steps, both price and volatility matching are required. The tree structure follows:

$$r_{i,j} = r_{i,1} \cdot e^{2(j-1)\sigma\sqrt{\Delta t}}$$

Where \(r_{i,j}\) is the short rate at time step \(i\) and node \(j\), and \(\sigma\) is the volatility parameter.

% Iterate through remaining time steps for i = 2:N thisPrice = observedData.price(i); thisMaturity = observedData.m(i); thisVolatility = observedData.volatility(i); thisPriceAndVol = [thisPrice, thisVolatility]; % Minimize squared error in both price and volatility thisError = @(params) sum((thisPriceAndVol - bondTree(params,i,dt,shortTree)).^2); thisParam = fminsearch(thisError, startParam); % Build tree with optimized parameters thisBottomR = thisParam(1); thisSigma = thisParam(2); shortTree(i,1) = thisBottomR; for j = 2:i shortTree(i,j) = thisBottomR*exp(2*(j-1)*thisSigma*sqrt(dt)); end end

The bondTree function prices a zero-coupon bond using backward induction through the tree and calculates the implied volatility from the ratio of up and down state bond yields. This ensures simultaneous calibration to both price and volatility data.

MBS Valuation

The mortgage-backed security is modeled as a portfolio of fixed monthly payments from a 30-year mortgage pool with an initial outstanding loan balance of $100 million and a continuous compounding rate of 7%.

Mortgage Cash Flows

The monthly payment is calculated using the standard annuity formula, converted to account for continuous compounding:

mortgageRate = 0.07; % continuous compounding amortizationYears = 30; OlbZero = 100000000; % $100 million % Convert continuous rate to monthly monthlyRate = (exp(mortgageRate/12) - 1); % Calculate fixed monthly payment monthlyPayment = OlbZero * (monthlyRate*(1+monthlyRate)^(amortizationYears*12)) / ... ((1+monthlyRate)^(amortizationYears*12) - 1);

For each month, the payment is split between interest on the outstanding balance and principal repayment:

% Initialize first period mortgage.interest(1) = OlbZero * monthlyRate; mortgage.principal(1) = mortgage.payment(1) - mortgage.interest(1); mortgage.outstandingOLB(1) = OlbZero - mortgage.principal(1); % Calculate for all subsequent months for i = 2:amortizationYears*12 mortgage.interest(i) = mortgage.outstandingOLB(i-1) * monthlyRate; mortgage.principal(i) = mortgage.payment(i) - mortgage.interest(i); mortgage.outstandingOLB(i) = mortgage.outstandingOLB(i-1) - mortgage.principal(i); end

Valuation Without Prepayment

The base case values the MBS assuming no prepayment occurs. The value is calculated by backward induction through the short rate tree, discounting expected cash flows at each node:

% Initialize terminal nodes mortgageTree(end,:) = monthlyPayment * exp(-shortTree(end,:) * dt); % Backward induction for a = 1:amortizationYears*12-1 for b = 1:amortizationYears*12-1 mortgageTree(end-a,b) = (0.5*mortgageTree(end-a+1,b) + ... 0.5*mortgageTree(end-a+1,b+1)) * ... exp(-shortTree(end-a,b)*dt) + monthlyPayment; end end valueMortgageNoPrepayment = mortgageTree(1,1);

Valuation With Prepayment Option

The prepayment option allows the mortgage pool to be refinanced at any point. At each node, the mortgage value is capped by the outstanding loan balance, representing the prepayment option being exercised:

% Initialize prepayment tree with terminal values mortgageTreeWithPrepayment = NaN(amortizationYears*12, amortizationYears*12); for c = 1:amortizationYears*12 mortgageTreeWithPrepayment(end,c) = min(mortgage.outstandingOLB(end), ... mortgageTree(end,c)); end % Backward induction with prepayment constraint at each node eend = amortizationYears*12 - 1; for d = 2:amortizationYears*12-1 for e = 1:eend mortgageTreeWithPrepayment(end-d,e) = ... min(mortgage.outstandingOLB(end-d), ... (0.5*mortgageTreeWithPrepayment(end-d+1,e) + ... 0.5*mortgageTreeWithPrepayment(end-d+1,e+1)) * ... exp(-shortTree(end-d,e)*dt) + monthlyPayment); eend = amortizationYears*12 - d; % Update loop bound for tree structure end end valueMortgageWithPrepayment = mortgageTreeWithPrepayment(1,1);

The difference between these values represents the cost of the embedded prepayment option to the MBS holder:

$$\text{Option Value} = \text{Value}_{\text{no prepayment}} - \text{Value}_{\text{with prepayment}}$$

Duration and Convexity Analysis

Duration and convexity measure the sensitivity of the MBS value to interest rate changes. These are computed by analyzing values at nearby nodes in the short rate tree.

Duration

Duration measures the first-order sensitivity of price to interest rate changes:

$$D = -\frac{1}{P} \frac{\partial P}{\partial r}$$

In the discrete tree framework, this is approximated using finite differences:

% Extract rates and values from tree nodes ru = shiftedTree(2,2); % up state rate rd = shiftedTree(2,1); % down state rate puNo = shiftedTreeValues(3); % price in up state (no prepayment) pdNo = shiftedTreeValues(4); % price in down state (no prepayment) % Calculate duration durationNoPrepayment = -1/shiftedTreeValues(1) * ((puNo - pdNo)/(ru - rd));

Convexity

Convexity captures the second-order sensitivity, measuring how duration itself changes with interest rates:

$$C = D^2 - \frac{1}{P}\frac{\partial^2 P}{\partial r^2}$$

The implementation uses a second-order finite difference approximation:

% Extract rates and values from time step 3 for second-order derivatives ruu = shiftedTree(3,3); % up-up state rate rud = shiftedTree(3,2); % up-down state rate rdd = shiftedTree(3,1); % down-down state rate puuNo = shiftedTreeValues(5); % price at up-up node pudNo = shiftedTreeValues(6); % price at up-down node pddNo = shiftedTreeValues(7); % price at down-down node % Calculate durations at up and down nodes DuNo = -1/puNo * ((puuNo - pudNo)/(ruu - rud)); DdNo = -1/pdNo * ((pudNo - pddNo)/(rud - rdd)); % Calculate convexity using second-order finite differences convexityNoPrepayment = durationNoPrepayment^2 - ((DuNo - DdNo)/(ru - rd));

Comparative Analysis

The analysis computes value, duration, and convexity across a range of interest rate scenarios by scaling the entire short rate tree. This reveals how the prepayment option affects risk characteristics:

% Analyze over range of tree multipliers TreeMultiplierVector = (0.1:0.02:2)'; for k = 1:n multiplier = TreeMultiplierVector(k); shiftedTree = shortTree .* multiplier; % Calculate MBS values, duration, and convexity shiftedTreeValues = mortgageValue(amortizationYears, monthlyPayment, ... mortgage, shiftedTree, dt); % Store results for both prepayment cases interestDependentValues.valueNoPrepayment(k) = shiftedTreeValues(1); interestDependentValues.valueWithPrepayment(k) = shiftedTreeValues(2); % ... duration and convexity calculations ... end
Key Insights
  • Negative Convexity: MBS with prepayment typically exhibit negative convexity at low interest rates, where prepayment is most likely. This means duration increases as rates rise (opposite of standard bonds).
  • Duration Reduction: The prepayment option generally reduces effective duration compared to non-prepayable mortgages, especially in low-rate environments.
  • Value Impact: The prepayment option always reduces MBS value from the investor's perspective, with the impact most pronounced when rates are low.

Results and Interpretation

Theoretical Framework

The prepayment option can be understood as a call option on the mortgage pool held by the borrowers. When interest rates fall below the mortgage rate, refinancing becomes economically attractive. This creates asymmetric risk profiles:

  • Rising Rates: Prepayment slows, extending effective duration
  • Falling Rates: Prepayment accelerates, shortening effective duration and capping price appreciation

Practical Implications

Investment Considerations
  • Yield Enhancement: MBS typically offer higher yields than comparable Treasury securities to compensate for prepayment risk and negative convexity
  • Interest Rate Views: MBS are most attractive when rates are expected to remain stable or rise moderately
  • Portfolio Role: Duration and convexity characteristics differ substantially from traditional fixed-income securities
  • Risk Management: Hedging strategies must account for changing duration as rates move

Model Limitations

This analysis makes several simplifying assumptions:

  • Deterministic prepayment behavior (exercised whenever economically rational)
  • No transaction costs or refinancing delays
  • Single-factor interest rate model
  • No credit risk considerations
  • Homogeneous mortgage pool characteristics

More sophisticated models might incorporate:

  • Behavioral prepayment models (e.g., PSA curves)
  • Multiple interest rate factors
  • Credit risk and defaults
  • Heterogeneous mortgage pools with different characteristics
  • Servicing fees and other costs

Conclusion

This project demonstrates a complete framework for valuing mortgage-backed securities with embedded prepayment options. By combining term structure modeling (Nelson-Siegel), interest rate dynamics (BDT tree), and option pricing techniques, we can quantify the value and risk characteristics of these complex instruments.

The analysis reveals how prepayment options fundamentally alter the risk profile of mortgage-backed securities, introducing negative convexity and path-dependent duration. These characteristics make MBS valuation more complex than standard fixed-income securities but also create opportunities for investors who understand and can manage these risks.

The MATLAB implementation provides a practical tool for exploring these dynamics across different interest rate scenarios, making it valuable for both educational purposes and real-world analysis.
