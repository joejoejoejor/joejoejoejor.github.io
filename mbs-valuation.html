Valuing MBS Options

A Quantitative Analysis of Mortgage-Backed Securities with Prepayment Features

Overview

This project values Mortgage-Backed Securities (MBS) with embedded prepayment options using the Black-Derman-Toy framework calibrated via Nelson-Siegel yield curve fitting. Analysis quantifies the impact of prepayment on value, duration, and convexity.

Key Challenge: Homeowners hold an embedded call option—when rates decline, they refinance, capping MBS price appreciation and introducing negative convexity.

Methodology
  • Nelson-Siegel model for term structure estimation (yields and volatilities)
  • Black-Derman-Toy recombining binomial short rate tree (360 monthly steps)
  • Backward induction MBS valuation with/without prepayment constraints
  • Finite difference calculation of duration and convexity across rate scenarios

Nelson-Siegel Model

The Nelson-Siegel model provides a parsimonious four-parameter framework for fitting term structures. It captures level (\(\beta_0\)), slope (\(\beta_1\)), curvature (\(\beta_2\)), and the maturity at which curvature peaks (\(\tau\)).

Model Specification

$$Y(m) = \beta_0 + (\beta_1 + \beta_2)\frac{1-e^{-m/\tau}}{m/\tau} - \beta_2 e^{-m/\tau}$$

Parameter Estimation via Nonlinear Optimization

Parameters are estimated by minimizing sum of squared errors using MATLAB's fminsearch, applied separately to yield and volatility data.

MATLAB: Nelson-Siegel Fitting (nelsonSiegel_MBS_Johannes.m)
% Import data yieldData = readtable('yieldAndVolatility2000.csv'); startPar = [1, 1, 1, 1]; % Initial guess: [beta0, beta1, beta2, tau] % Define error functions for yields and volatilities errorNelsonSiegelYield = @(par) (sum((yieldData.y - ( ... par(1) + (par(2)+par(3)).*(1-exp(-yieldData.m./par(4)))./(yieldData.m./par(4)) ... - par(3).*exp(-yieldData.m./par(4)) )).^2)); errorNelsonSiegelVol = @(par) (sum((yieldData.vol - ( ... par(1) + (par(2)+par(3)).*(1-exp(-yieldData.m./par(4)))./(yieldData.m./par(4)) ... - par(3).*exp(-yieldData.m./par(4)) )).^2)); % Optimize parameters via unconstrained minimization [parMinYield, errorMinYield] = fminsearch(errorNelsonSiegelYield, startPar); [parMinVol, errorMinVol] = fminsearch(errorNelsonSiegelVol, startPar); % Create fitted functions for any maturity m fittedFunctionYield = @(m) ( parMinYield(1) + ... (parMinYield(2)+parMinYield(3)).*(1-exp(-m./parMinYield(4)))./(m./parMinYield(4)) ... - parMinYield(3).*exp(-m./parMinYield(4)) ); fittedFunctionVol = @(m) ( parMinVol(1) + ... (parMinVol(2)+parMinVol(3)).*(1-exp(-m./parMinVol(4)))./(m./parMinVol(4)) ... - parMinVol(3).*exp(-m./parMinVol(4)) ); % Generate fitted curves for all 360 monthly maturities month = (1:360)'; m = month./12; nelsonSiegelYields = fittedFunctionYield(m); nelsonSiegelVols = fittedFunctionVol(m);

Figure 1: Nelson-Siegel model fitting for yields (top) and volatilities (bottom). Observed market data points are shown with fitted curves interpolating across all maturities.

The fitted curves provide smooth term structures for yields and volatilities at all 360 monthly periods, essential inputs for the BDT short rate tree calibration.

Black-Derman-Toy Short Rate Tree

The BDT framework uses a recombining binomial tree calibrated to match zero-coupon bond prices and the term structure of volatility. At each time step \(i\), we solve for the lowest short rate \(r_{i,1}\) and volatility parameter \(\sigma\).

Tree Structure

Short rates in the tree follow: \(r_{i,j} = r_{i,1} \cdot e^{2(j-1)\sigma\sqrt{\Delta t}}\), ensuring a recombining structure where up-then-down equals down-then-up.

Calibration Algorithm

Initial Node: Calibrate to match the first zero-coupon bond price.

MATLAB: Initial Node Calibration (MBS_PartII_Johannes.m)
% First node: match observed bond price (no volatility matching) i = 1; thisPrice = observedData.price(i); thisMaturity = observedData.m(i); % Minimize squared error between model and market price thisError = @(r) (1*exp(-r*thisMaturity) - thisPrice)^2; thisR = fminsearch(thisError, startR); shortTree(i,1) = thisR;

Subsequent Nodes: Jointly calibrate to match both bond price and implied volatility.

MATLAB: Tree Construction with Price and Volatility Matching
% Iterate through remaining time steps for i = 2:N thisPrice = observedData.price(i); thisMaturity = observedData.m(i); thisVolatility = observedData.volatility(i); thisPriceAndVol = [thisPrice, thisVolatility]; % Minimize sum of squared errors in both price and volatility thisError = @(params) sum((thisPriceAndVol - bondTree(params,i,dt,shortTree)).^2); thisParam = fminsearch(thisError, startParam); % Populate tree with optimized parameters thisBottomR = thisParam(1); % Lowest rate at this time step thisSigma = thisParam(2); % Volatility parameter shortTree(i,1) = thisBottomR; for j = 2:i shortTree(i,j) = thisBottomR * exp(2*(j-1)*thisSigma*sqrt(dt)); end end
MATLAB: Bond Pricing Function (bondTree.m)
function [out] = bondTree(params, t, dt, shortTree) % Construct short rate row with trial parameters shortRow = NaN(1,t+1); for i = 1:t shortRow(i) = params(1)*exp(2*(i-1)*params(2)*sqrt(dt)); end % Initialize bond tree, terminal nodes = 1 bTree = NaN(t+1, t+1); bTree(t+1, :) = 1; % Backward induction through tree for b = 1:t bTree(t,b) = (0.5*bTree(t+1,b) + 0.5*bTree(t+1,b+1)) * exp(-shortRow(b)*dt); end for a = 1:t-1 r = t-a; for b = 1:r bTree(r,b) = (0.5*bTree(r+1,b) + 0.5*bTree(r+1,b+1)) * exp(-shortTree(r,b)*dt); end end % Calculate price and implied volatility outPrice = bTree(1,1); highyield = -1/dt*log(bTree(2,2)); lowyield = -1/dt*log(bTree(2,1)); outVol = 1/(2*sqrt(dt))*log(highyield/lowyield); out = [outPrice, outVol]; end

Figure 2: BDT short rate tree spanning 360 monthly time steps. The minimum (blue) and maximum (red) rate paths envelope all possible interest rate scenarios. Log scale emphasizes the exponential tree structure.

MBS Valuation

The MBS represents a 30-year mortgage pool with $100 million initial balance at 7% continuous compounding. Monthly cash flows consist of fixed payments split between interest and principal.

Mortgage Cash Flow Structure

MATLAB: Mortgage Payment Calculation (MBS_PartII_Johannes.m)
mortgageRate = 0.07; % continuous compounding amortizationYears = 30; OlbZero = 100000000; % $100 million initial balance % Convert continuous rate to monthly discrete rate monthlyRate = (exp(mortgageRate/12) - 1); % Calculate fixed monthly payment using annuity formula monthlyPayment = OlbZero * (monthlyRate*(1+monthlyRate)^(amortizationYears*12)) / ... ((1+monthlyRate)^(amortizationYears*12) - 1); % Build amortization schedule mortgage.interest(1) = OlbZero * monthlyRate; mortgage.principal(1) = mortgage.payment(1) - mortgage.interest(1); mortgage.outstandingOLB(1) = OlbZero - mortgage.principal(1); for i = 2:amortizationYears*12 mortgage.interest(i) = mortgage.outstandingOLB(i-1) * monthlyRate; mortgage.principal(i) = mortgage.payment(i) - mortgage.interest(i); mortgage.outstandingOLB(i) = mortgage.outstandingOLB(i-1) - mortgage.principal(i); end

Valuation Without Prepayment

Base case: value the MBS assuming no prepayment. Use backward induction through the short rate tree, discounting expected cash flows.

MATLAB: MBS Valuation Without Prepayment (mortgageValue.m)
% Initialize terminal nodes with final payment discounted one period mortgageTree(end,:) = monthlyPayment * exp(-shortTree(end,:) * dt); % Backward induction: discount expected value and add current payment for a = 1:amortizationYears*12-1 for b = 1:amortizationYears*12-1 mortgageTree(end-a,b) = (0.5*mortgageTree(end-a+1,b) + ... 0.5*mortgageTree(end-a+1,b+1)) * ... exp(-shortTree(end-a,b)*dt) + monthlyPayment; end end valueMortgageNoPrepayment = mortgageTree(1,1);

Valuation With Prepayment Option

Key insight: Borrowers hold an American call option on the mortgage. At any node, if the mortgage value exceeds the outstanding balance, rational borrowers prepay.

MATLAB: MBS Valuation With Prepayment Option
% Initialize terminal nodes with prepayment constraint for c = 1:amortizationYears*12 mortgageTreeWithPrepayment(end,c) = min(mortgage.outstandingOLB(end), ... mortgageTree(end,c)); end % Backward induction with prepayment constraint at each node eend = amortizationYears*12 - 1; for d = 2:amortizationYears*12-1 for e = 1:eend % Calculate continuation value continuationValue = (0.5*mortgageTreeWithPrepayment(end-d+1,e) + ... 0.5*mortgageTreeWithPrepayment(end-d+1,e+1)) * ... exp(-shortTree(end-d,e)*dt) + monthlyPayment; % Cap at outstanding balance (prepayment option) mortgageTreeWithPrepayment(end-d,e) = min(mortgage.outstandingOLB(end-d), ... continuationValue); eend = amortizationYears*12 - d; end end valueMortgageWithPrepayment = mortgageTreeWithPrepayment(1,1);
$$\text{Prepayment Option Value} = V_{\text{no prepayment}} - V_{\text{with prepayment}}$$

Prepayment Modeling Mechanics

The prepayment decision is rational and deterministic in this model: borrowers prepay when the present value of remaining payments exceeds the outstanding loan balance. This occurs primarily when interest rates decline significantly below the mortgage rate.

Figure 3: Left - Prepayment speed increases exponentially as current rates fall below the mortgage rate (7%). Right - Outstanding balance declines faster with prepayment, reducing MBS cash flow duration.

Duration and Convexity Analysis

Duration and convexity quantify MBS price sensitivity to interest rate movements. Computed using finite differences from the short rate tree, these metrics reveal how prepayment options alter risk characteristics.

Duration: First-Order Sensitivity

$$D = -\frac{1}{P} \frac{\partial P}{\partial r} \approx -\frac{1}{P_0} \frac{P_u - P_d}{r_u - r_d}$$
MATLAB: Duration Calculation (MBS_PartII_Johannes.m)
% Extract rates and prices at up and down nodes ru = shiftedTree(2,2); % up state rate rd = shiftedTree(2,1); % down state rate puNo = shiftedTreeValues(3); % price in up state (no prepayment) pdNo = shiftedTreeValues(4); % price in down state (no prepayment) % Calculate duration via finite difference durationNoPrepayment = -1/shiftedTreeValues(1) * ((puNo - pdNo)/(ru - rd)); % Repeat for prepayment case puWith = shiftedTreeValues(8); pdWith = shiftedTreeValues(9); durationWithPrepayment = -1/shiftedTreeValues(2) * ((puWith - pdWith)/(ru - rd));

Convexity: Second-Order Sensitivity

$$C = D^2 - \frac{1}{P}\frac{\partial^2 P}{\partial r^2} = D^2 - \frac{D_u - D_d}{r_u - r_d}$$
MATLAB: Convexity Calculation
% Extract rates and prices at time step 3 ruu = shiftedTree(3,3); % up-up state rud = shiftedTree(3,2); % up-down state rdd = shiftedTree(3,1); % down-down state puuNo = shiftedTreeValues(5); pudNo = shiftedTreeValues(6); pddNo = shiftedTreeValues(7); % Calculate local durations at up and down nodes DuNo = -1/puNo * ((puuNo - pudNo)/(ruu - rud)); DdNo = -1/pdNo * ((pudNo - pddNo)/(rud - rdd)); % Convexity from second-order finite differences convexityNoPrepayment = durationNoPrepayment^2 - ((DuNo - DdNo)/(ru - rd)); % Repeat for prepayment case puuWith = shiftedTreeValues(10); pudWith = shiftedTreeValues(11); pddWith = shiftedTreeValues(12); DuWith = -1/puWith * ((puuWith - pudWith)/(ruu - rud)); DdWith = -1/pdWith * ((pudWith - pddWith)/(rud - rdd)); convexityWithPrepayment = durationWithPrepayment^2 - ((DuWith - DdWith)/(ru - rd));

Key Insights
  • Negative Convexity: MBS with prepayment exhibit negative convexity at low rates where prepayment is most likely, causing duration to rise as rates increase.
  • Duration Compression: Prepayment option significantly reduces effective duration in low-rate environments, limiting price appreciation.
  • Value Impact: Option value (difference between curves) peaks when rates are low, representing maximum borrower incentive to refinance.

Conclusion

This framework combines Nelson-Siegel term structure modeling, Black-Derman-Toy interest rate dynamics, and American option pricing to value MBS with embedded prepayment options. The analysis quantifies how prepayment fundamentally alters risk characteristics, introducing negative convexity and path-dependent duration.

Results demonstrate that prepayment options create asymmetric payoffs: MBS investors sacrifice upside potential in declining rate environments while retaining downside exposure when rates rise. This makes MBS valuation more complex than standard fixed-income securities but creates opportunities for investors who can model and hedge these risks effectively.

Results and Interpretation

Prepayment Option as Embedded Call

The prepayment option is economically equivalent to a call option on the mortgage pool held by borrowers. When rates fall below the mortgage rate, refinancing becomes attractive, creating asymmetric risk:

  • Rising Rates: Prepayment slows → duration extends → MBS behaves like long-term bond
  • Falling Rates: Prepayment accelerates → duration shortens → price appreciation capped

Investment Implications

Portfolio Considerations
  • Yield Enhancement: MBS offer yield premium over Treasuries to compensate for prepayment risk and negative convexity
  • Rate Environment: Most attractive when rates are stable or expected to rise moderately; underperform in rallies
  • Dynamic Hedging: Changing duration requires active hedge ratio adjustments as rates move

Model Limitations and Extensions

Simplifications: Deterministic prepayment (rational exercise only), single-factor rates, no transaction costs, no credit risk.

Potential Extensions: Behavioral prepayment models (PSA curves), multi-factor term structure, credit defaults, heterogeneous pools, servicing fees.
